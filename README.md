# 📚 수학 학습 & 건강 관리 도우미

당곡고등학교 학생들을 위한 수학 학습 관리 및 건강 관리 통합 웹앱입니다.
Streamlit Cloud에서 손쉽게 배포할 수 있습니다.

## ✨ 주요 기능

### 1. 수학 문제풀이 및 오답노트
- 문제를 풀고 정답/오답을 기록
- 단원별, 난이도별 분류
- 틀린 문제에 대한 풀이 메모 작성

### 2. 오답 및 정답률 분석
- 전체 정답률 시각화
- 단원별 정답률 비교 차트
- 시간에 따른 학습 추이 확인

### 3. 취약점 분석
- 정답률이 낮은 단원 자동 추출
- 집중 학습이 필요한 영역 추천

### 4. 건강 관리
- 눈 휴식 알림 (20-20-20 규칙)
- 스트레칭 알림
- 수면 시간 기록
- 집중 시간(공부 시간) 기록 및 통계
